The problem

One helpdesk for many companies on one code base. A forgotten WHERE must never show foreign tickets.

The result

    Decisions

    • 0001

      Pool for small companies, silo for enterprise

      Small companies share one database, large ones get their own. The cost is connections and a migration for every silo.

    • 0002

      Row level security instead of a schema per company

      The filter lives on every table inside the database. The cost is a little work per query and strict rules for every connection.

    • 0003

      The company comes from a signed token

      It never sits in the URL and cannot be forged. The cost is that a token stays valid until it expires.

    • 0004

      Limit per company in memory

      One bucket per company and plan, with no database behind it. The cost is that it counts per instance, not exactly across all.
